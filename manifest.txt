Develop a production-grade Spring Boot starter library called `secret-loader-spring-boot-starter` that dynamically loads secrets and injects them into the Spring Environment before application startup.

Requirements:

1. Technology Stack

* Java 17
* Spring Boot 3.x
* Maven
* Support Spring Boot auto-configuration

2. Core Features

* Load secrets before datasource initialization
* Avoid hardcoded credentials in `application.yaml`
* Do not rely on environment variables
* Work in Docker, Kubernetes, CI/CD pipelines, and temporary containers
* Inject secrets dynamically into Spring Environment
* Reusable across multiple microservices

3. Implementation Requirements

* Use `EnvironmentPostProcessor`
* Register processor using:

  * `META-INF/spring.factories` (for compatibility)
  * `META-INF/spring/org.springframework.boot.autoconfigure.AutoConfiguration.imports` (for Spring Boot 3 preferred approach)
* Create modular architecture with:

  * `SecretService` interface
  * Multiple implementations:

    * REST API secret loader
    * File-based secret loader
    * Vault-based loader placeholder
* Add auto-configuration support
* Add configuration properties support using:

  * `@ConfigurationProperties`
  * `@EnableConfigurationProperties`

4. Configuration Example

Library user should configure:

```yaml
secret:
  loader:
    enabled: true
    source: api
    api-url: https://secret-api.company.com/secrets
    api-token: xyz123
```

5. Secret Injection Example

Inject dynamically:

```properties
spring.datasource.url
spring.datasource.username
spring.datasource.password
jwt.secret
redis.password
kafka.password
```

6. REST Secret Loader

* Use `RestTemplate` or `WebClient`
* Support Bearer Token authentication
* Parse JSON response
* Handle API failures gracefully
* Add retry mechanism

7. Security Features

* Never log secrets
* Mask sensitive values in logs
* Support encrypted API response
* Add optional AES decryption utility
